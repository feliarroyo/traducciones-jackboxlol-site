Website developed for the **Jackbox en español** translation project, containing all information and downloads related to it.

## Features

- **Responsive UI:** A modern, colorful interface built for seamless scaling across desktop and mobile.
- **Dynamic Download Matrix:** Accessible toggle components designed to route users to the exact translation patch for their specific OS and storefront.
- **Static Markdown Blog:** A dedicated news section that parses local `.md` files into a fully styled, blog-like feed.
- **Optimized Assets:** Core web vitals prioritized through native image and video optimization for rapid page loads.
- **Smooth Animations:** Unobtrusive, lightweight motion graphics applied throughout the DOM to improve interface feedback.
- **Legacy URL Preservation:** Configured wildcard 301 redirects to safely migrate SEO equity and user traffic from the previous Google Sites deployment.

## How to use locally

To use locally, run the following commands:

```bash
git clone https://github.com/feliarroyo/traducciones-jackboxlol-site.git
cd traducciones-jackboxlol-site/jackbox-espanol
npm install
npm run dev
```

Then, open http://localhost:3000 with your browser to see the site locally.
